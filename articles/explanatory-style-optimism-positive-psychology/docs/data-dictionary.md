# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `domain` | categorical | n/a | Applied setting such as education, work, health, community, transition, or sport. |
| `neg_stability` | numeric | higher is more pessimistic for bad events | Degree to which negative-event causes are interpreted as stable or lasting. |
| `neg_globality` | numeric | higher is more pessimistic for bad events | Degree to which negative-event causes are interpreted as global or pervasive. |
| `neg_personalization` | numeric | higher is more self-condemning | Degree to which negative events are interpreted as personally defining rather than specific, contextual, or revisable. |
| `pos_stability` | numeric | higher is more adaptive for good events | Degree to which positive-event causes are interpreted as stable enough to matter. |
| `pos_globality` | numeric | higher is more adaptive for good events | Degree to which positive-event causes are interpreted as generalizable or meaningful beyond a single accident. |
| `pos_internal_effort` | numeric | higher is more adaptive when realistic | Degree to which positive events are connected to effort, skill, support use, preparation, or meaningful agency. |
| `setback_intensity` | numeric | higher is more severe | Severity, recurrence, stakes, or difficulty of setback exposure. |
| `controllability_score` | numeric | higher is more controllability | Degree to which the person has realistic influence over the situation. |
| `agency_score` | numeric | higher is better | Perceived capacity to act, revise, seek help, or influence future outcomes. |
| `support_score` | numeric | higher is better | Relational, institutional, educational, workplace, or community support. |
| `persistence_score` | numeric | higher is better | Continued effort, re-engagement, help-seeking, revision, or task persistence after setback. |
| `hope_score` | numeric | higher is better | Future-oriented agency and pathways belief. |
| `wellbeing_score` | numeric | higher is better | Synthetic well-being or flourishing outcome score. |
| `distress_score` | numeric | higher is worse | Distress, discouragement, anxiety, shame, or helplessness-related burden. |

## Context audit variables

| Variable | Description |
|---|---|
| `feedback_specificity` | Whether the setting gives specific, useful, non-totalizing feedback. |
| `revision_pathways` | Whether people have genuine opportunities to revise, retry, repair, or improve. |
| `fairness_of_evaluation` | Whether evaluation is fair, transparent, and non-arbitrary. |
| `agency_support` | Whether the setting supports meaningful action rather than helplessness. |
| `controllability_support` | Whether effort has a realistic relationship to outcomes. |
| `psychological_safety` | Whether mistakes can be discussed without humiliation or identity attack. |
| `support_availability` | Whether practical, relational, instructional, or institutional support exists. |
| `anti_blame_review` | Review of whether optimism language is being used to blame people for real conditions. |
| `privacy_safeguards` | Protection for attributional, setback, mental-health-adjacent, and resilience data. |
| `cultural_adaptation` | Attention to cultural, religious, linguistic, social, and institutional variation in causal explanation. |
| `measurement_quality` | Quality of measurement design, documentation, interpretation limits, and validation. |
| `overall_context_quality` | Transparent average-like summary used for teaching; not a validated score. |
