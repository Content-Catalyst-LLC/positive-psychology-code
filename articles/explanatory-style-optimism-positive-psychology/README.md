# Explanatory Style and Optimism in Positive Psychology

Professional computational scaffolding for the article `explanatory-style-optimism-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for explanatory style and optimism, including negative-event stability, globality, personalization, positive-event integration, setback intensity, controllability, agency, support, persistence, hope, wellbeing, distress, context-adjusted agency, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, positive psychology researchers, attribution researchers, resilience researchers, educational psychologists, counseling researchers, health psychologists, organizational psychologists, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis support, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, benefits eligibility decisions, or individual psychological assessment. Applied use in schools, workplaces, healthcare, counseling, public services, community programs, organizational decision-making, or resilience-training systems would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, anti-coercion review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level attributional-burden, optimism, positive-event integration, and context-adjusted agency scoring example in C. |
| `cpp/` | C++ implementation for typed explanatory-style indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and institutional/context datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for explanatory-style scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for attributional burden, agency, support, setback intensity, persistence, hope, and wellbeing dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, explanatory-style indices, context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures attributional-style, persistence, hope, wellbeing, and distress modeling. |
| `rust/` | Rust implementation for safe, explicit explanatory-style indicator scoring. |
| `sql/` | Relational schema and analytical views for explanatory-style research data. |
