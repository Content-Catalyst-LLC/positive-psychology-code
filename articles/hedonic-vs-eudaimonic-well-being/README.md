# Hedonic vs Eudaimonic Well-Being

Professional computational scaffolding for the article `hedonic-vs-eudaimonic-well-being` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for hedonic and eudaimonic well-being, including life satisfaction, positive affect, negative affect, autonomy, personal growth, purpose in life, positive relations, environmental mastery, self-acceptance, contextual support, stress load, integrated flourishing, measurement reliability, longitudinal modeling, and network structures of well-being.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, well-being researchers, public-policy analysts, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, public-benefits eligibility decisions, or individual well-being assessment. Applied use in health, education, employment, public services, organizational decision-making, public policy, or community intervention would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, community interpretation, bias and fairness review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level hedonic/eudaimonic composite example in C. |
| `cpp/` | C++ implementation for typed integrated well-being scoring. |
| `data/` | Synthetic panel, network, and item-family datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for hedonic/eudaimonic dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, and diagnostics. |
| `python/` | Python workflow for composite indicators, PCA, Graphical Lasso networks, and bootstrap stability. |
| `r/` | R workflow for mixed models, reliability checks, interactions, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for hedonic/eudaimonic well-being data. |
