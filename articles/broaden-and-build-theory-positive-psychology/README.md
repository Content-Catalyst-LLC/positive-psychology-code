# Broaden-and-Build Theory in Positive Psychology

Professional computational scaffolding for the article `broaden-and-build-theory-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for Broaden-and-Build Theory and positive emotion research, including positive emotion, negative emotion, cognitive flexibility, exploratory behavior, affiliative behavior, social support, resilience, stress arousal, contextual safety, resource building, upward spirals, stress recovery, longitudinal mixed modeling, mechanism networks, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to positive psychology researchers, psychologists, emotion researchers, resilience researchers, educational researchers, organizational researchers, well-being scientists, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are professional research scaffolds, not validated clinical instruments or individual decision tools. Applied work with real people, schools, workplaces, healthcare settings, or community programs requires validated measures, appropriate ethics review, privacy safeguards, cultural adaptation, trauma-informed framing, domain expertise, and careful communication of uncertainty.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level broadening, resource, and net-adaptation scoring example in C. |
| `cpp/` | C++ implementation for typed broaden-and-build mechanism scoring. |
| `data/` | Synthetic panel, network, item-family, recovery, and practice-quality datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for broaden-and-build mechanism scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for positive emotion, broadening, resource building, recovery, and upward spirals. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, broadening/resource indices, practice-quality audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for longitudinal broadening, resilience, and recovery modeling. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for broaden-and-build research data. |
