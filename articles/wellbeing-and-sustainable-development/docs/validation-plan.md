# Validation Plan

This plan is intended for professional research use with real, ethically collected data.

## Data validation

- Confirm data provenance and collection context.
- Confirm scale direction and units.
- Check missingness by country, region, year, indicator, and domain.
- Evaluate whether missingness is plausibly MCAR, MAR, or MNAR.
- Inspect outliers and impossible values.
- Document inclusion, exclusion, and transformation rules.

## Indicator validation

- Estimate internal consistency for indicator families where appropriate.
- Inspect correlations among human development, well-being, institutional, and ecological indicators.
- Test dimensional structure using PCA or factor analysis.
- Avoid collapsing indicators when dimensions behave differently.
- Report sensitivity to weighting choices.

## Model validation

- Compare complete-case, imputed, and sensitivity models.
- Inspect mixed-model residuals and random-effects assumptions.
- Test whether longitudinal trends are robust to country-level heterogeneity.
- Bootstrap network centrality and edge stability.
- Avoid causal claims unless the design supports them.

## Ethical validation

- Avoid using rankings to stigmatize countries, cultures, or communities.
- Disaggregate results where data allow and where interpretation is responsible.
- Treat inequality and ecological exposure as structural conditions, not individual deficits.
- Document limits clearly in outputs and article-adjacent interpretation.
