# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `life_expectancy` | numeric | higher is better | Health and longevity capability. |
| `education_index` | numeric | higher is better | Educational access, attainment, and capability development. |
| `income_index` | numeric | higher is better | Material resources and income capacity. |
| `life_satisfaction` | numeric | higher is better | Cognitive evaluation of life as a whole. |
| `institutional_quality` | numeric | higher is better | Governance capacity, legitimacy, public-sector reliability, and fairness. |
| `ecological_stability` | numeric | higher is better | Environmental condition and future-oriented ecological viability. |
| `social_trust` | numeric | higher is better | Social cohesion, cooperation, and trust. |
| `inequality_index` | numeric | higher is worse | Inequality, unequal burden, and distributional stress. |
| `resilience_capacity` | numeric | higher is better | Institutional, community, and adaptive capacity under stress. |
| `basic_services` | numeric | higher is better | Access to public services, infrastructure, health, sanitation, and social protection. |

## Indicator-bank variables

The `sustainable_wellbeing_indicator_bank.csv` file includes synthetic item-level / indicator-family variables:

- `swb1` to `swb3`: subjective well-being indicators;
- `cap1` to `cap3`: human capability indicators;
- `inst1` to `inst3`: institutional quality indicators;
- `eco1` to `eco3`: ecological stability indicators;
- `res1` to `res3`: resilience capacity indicators.

These variables are designed for reliability, dimensional inspection, and teaching examples.
