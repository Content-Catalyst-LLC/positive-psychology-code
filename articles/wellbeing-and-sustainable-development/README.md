# Well-Being and Sustainable Development

Professional computational scaffolding for the article `wellbeing-and-sustainable-development` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for well-being and sustainable development, including human development indicators, subjective well-being, institutional quality, ecological stability, inequality, resilience capacity, basic services, intergenerational sustainability, and network structures of sustainable flourishing.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, sustainable-development researchers, public-policy analysts, graduate students, methods instructors, and interdisciplinary well-being research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, or individual well-being assessment. Applied use in health, employment, education, organizational decision-making, public services, or public-policy evaluation would require validated instruments, domain expertise, transparent measurement design, informed consent where appropriate, privacy safeguards, bias and fairness review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level sustainable flourishing composite example in C. |
| `cpp/` | C++ implementation for typed sustainable development scoring. |
| `data/` | Synthetic panel, network, and indicator-level datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for sustainable well-being dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, and diagnostics. |
| `python/` | Python workflow for composite indicators, PCA, Graphical Lasso networks, and bootstrap stability. |
| `r/` | R workflow for longitudinal mixed models, reliability checks, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for sustainable well-being data. |
