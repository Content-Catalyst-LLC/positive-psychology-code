# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `domain` | categorical | n/a | Applied setting such as education, health, counseling, career, or community. |
| `agency_score` | numeric | higher is better | Motivational energy and perceived capacity to sustain movement toward goals. |
| `pathways_score` | numeric | higher is better | Perceived capacity to generate workable routes and alternative routes toward goals. |
| `goal_clarity` | numeric | higher is better | Specificity, value, and clarity of goal targets. |
| `goal_progress` | numeric | higher is better | Perceived or measured progress toward goals. |
| `wellbeing_score` | numeric | higher is better | Synthetic well-being or flourishing outcome score. |
| `meaning_score` | numeric | higher is better | Perceived meaning, purpose, or significance connected to goals. |
| `stress_load` | numeric | higher is worse | Contextual strain and stress burden. |
| `obstacle_intensity` | numeric | higher is worse | Severity or density of barriers to goal pursuit. |
| `social_support` | numeric | higher is better | Relational support for agency, persistence, and route generation. |
| `resource_access` | numeric | higher is better | Access to material, institutional, informational, or practical resources. |
| `goal_revision_quality` | numeric | higher is better | Adaptive revision of goals when persistence is no longer useful or feasible. |
| `context_support` | numeric | higher is better | Overall supportiveness of the surrounding context for hope and goal pursuit. |

## Context-support audit variables

| Variable | Description |
|---|---|
| `goal_clarity_support` | Degree to which the setting helps clarify meaningful and realistic goals. |
| `agency_support` | Degree to which the setting supports self-directed movement and motivational energy. |
| `pathways_support` | Degree to which the setting supports route generation and alternative planning. |
| `resource_access_support` | Degree to which the setting provides resources needed for movement. |
| `obstacle_mapping_quality` | Quality of barrier identification and realistic planning. |
| `privacy_safeguards` | Protection for goal, obstacle, stress, and well-being data. |
| `structural_barrier_review` | Attention to institutional and material barriers. |
| `responsible_language` | Degree to which language avoids forced hope, denial, or moralizing low hope. |
| `overall_context_quality` | Transparent average-like summary used for teaching; not a validated score. |

## Indicator-bank variables

- `agency1` to `agency2`: agency thinking indicators.
- `pathways1` to `pathways2`: pathways thinking indicators.
- `goal_clarity1` to `goal_clarity2`: goal clarity indicators.
- `progress1` to `progress2`: goal progress indicators.
- `wellbeing1` to `wellbeing2`: well-being indicators.
- `meaning1` to `meaning2`: meaning indicators.
- `stress1` to `stress2`: stress indicators, where higher is worse.
- `obstacle1` to `obstacle2`: obstacle indicators, where higher is worse.
- `support1` to `support2`: social support indicators.
- `resources1` to `resources2`: resource access indicators.
