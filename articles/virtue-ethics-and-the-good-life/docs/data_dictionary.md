# Data Dictionary

## Panel Dataset: `virtue_flourishing_panel.csv`

| Column | Description |
|---|---|
| `id` | Synthetic participant identifier |
| `wave` | Observation wave |
| `meaning` | Meaning or purpose indicator |
| `relationships` | Relational quality indicator |
| `accomplishment` | Accomplishment or effective action indicator |
| `positive_emotion` | Positive affect indicator |
| `strengths_wisdom` | Wisdom-related character-strength domain |
| `strengths_courage` | Courage-related character-strength domain |
| `strengths_humanity` | Humanity-related character-strength domain |
| `strengths_justice` | Justice-related character-strength domain |
| `strengths_temperance` | Temperance-related character-strength domain |
| `strengths_transcendence` | Transcendence-related character-strength domain |
| `reflective_judgment` | Practical wisdom proxy |
| `institutional_support` | Perceived institutional support |
| `stress_load` | Stress burden or destabilizing pressure |
| `virtue_index` | Average of virtue-domain scores |
| `flourishing` | Generated composite target |
