# Method Notes

This companion scaffold treats PERMA as a multidimensional, profile-based, context-sensitive model of flourishing.

A working PERMA index is:

```text
perma_index =
  positive_emotion
+ engagement
+ relationships
+ meaning
+ accomplishment
```

A working PERMA balance model is:

```text
perma_balance =
  - variance(positive_emotion, engagement, relationships, meaning, accomplishment)
```

A working institutional-quality model is:

```text
institutional_quality =
  institutional_support
+ autonomy_support
+ fairness
+ psychological_safety
+ access
- institutional_barriers
- workload_strain
```

A working context-adjusted flourishing model is:

```text
context_adjusted_flourishing =
  flourishing
+ perma_index
+ institutional_quality
+ perma_balance
```

## Recommended research workflow

1. Inspect missingness, distributions, and scale direction.
2. Direction-correct institutional barriers and workload strain where needed.
3. Evaluate reliability separately for each PERMA component and institutional context family.
4. Preserve the five-domain PERMA profile before reducing it to a total score.
5. Calculate PERMA balance or profile dispersion to identify uneven flourishing profiles.
6. Measure autonomy, fairness, safety, access, support, barriers, and workload strain.
7. Model flourishing and life satisfaction separately where possible.
8. Use network models as exploratory PERMA-system maps, not causal proof.
9. Interpret results in relation to culture, development, institutional design, access, power, and social conditions.
10. Avoid treating PERMA scores as clinical measures, employment tools, school-ranking tools, disciplinary tools, benefits tools, or individual assessments.

## Scope and use

These examples use synthetic data for research workflow demonstration, methods development, documentation, and reproducible analysis. They are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, student ranking, employee evaluation, benefits eligibility decisions, or individual psychological assessment.
