# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `setting` | categorical | n/a | Applied setting such as education, work, health, community, transition, or public systems. |
| `positive_emotion` | numeric | higher is better | Joy, hope, gratitude, interest, serenity, and affective vitality. |
| `engagement` | numeric | higher is better | Absorption, flow, attention, challenge-skill fit, and investment in activity. |
| `relationships` | numeric | higher is better | Belonging, trust, support, care, and mutual recognition. |
| `meaning` | numeric | higher is better | Purpose, coherence, value, contribution, and connection to something larger than the self. |
| `accomplishment` | numeric | higher is better | Mastery, progress, goal pursuit, achievement, and valued development. |
| `flourishing_score` | numeric | higher is better | Synthetic global flourishing indicator. |
| `life_satisfaction` | numeric | higher is better | Synthetic global life-evaluation indicator. |
| `institutional_support` | numeric | higher is better | Environmental support for PERMA expression. |
| `institutional_barriers` | numeric | higher is worse | Structural or institutional constraints on well-being. |
| `autonomy_support` | numeric | higher is better | Ability to act with agency, voice, and meaningful choice. |
| `fairness_score` | numeric | higher is better | Fairness, transparency, and non-arbitrariness of the environment. |
| `psychological_safety` | numeric | higher is better | Ability to participate without humiliation, fear, or retaliation. |
| `access_score` | numeric | higher is better | Practical access to resources, relationships, opportunity, and participation. |
| `workload_strain` | numeric | higher is worse | Overload, stress, strain, or demand pressure. |

## Context audit variables

| Variable | Description |
|---|---|
| `positive_emotion_support` | Whether the setting supports dignity, rest, hope, gratitude, and humane conditions. |
| `engagement_support` | Whether the setting supports attention, skill use, learning, and meaningful challenge. |
| `relationship_support` | Whether the setting supports trust, belonging, care, and mutual recognition. |
| `meaning_support` | Whether the setting supports purpose, contribution, moral coherence, or larger value. |
| `accomplishment_support` | Whether the setting supports mastery, feedback, recognition, and fair goal pursuit. |
| `autonomy_support` | Whether people have meaningful voice, choice, and self-direction. |
| `fairness_support` | Whether rules, standards, burdens, access, and recognition are fair. |
| `psychological_safety` | Whether people can participate without humiliation, retaliation, or identity threat. |
| `access_support` | Whether resources and opportunities are realistically available. |
| `anti_coercion_review` | Review of whether well-being measurement is being used to pressure, rank, or discipline people. |
| `privacy_safeguards` | Protection for emotional, relational, meaning, accomplishment, and well-being data. |
| `cultural_adaptation` | Attention to cultural, religious, linguistic, social, and institutional variation in flourishing. |
| `measurement_quality` | Quality of measurement design, documentation, interpretation limits, and validation. |
| `overall_context_quality` | Transparent average-like summary used for teaching; not a validated score. |
