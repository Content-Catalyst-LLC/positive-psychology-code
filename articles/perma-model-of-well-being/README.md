# The PERMA Model of Well-Being

Professional computational scaffolding for the article `perma-model-of-well-being` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for the PERMA model of well-being, including positive emotion, engagement, relationships, meaning, accomplishment, flourishing, life satisfaction, profile balance, institutional support, institutional barriers, autonomy support, fairness, psychological safety, access, workload strain, longitudinal modeling, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to positive psychology researchers, well-being scientists, educational psychologists, organizational psychologists, public-health researchers, community researchers, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis support, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, benefits eligibility decisions, or individual psychological assessment. Applied use in schools, workplaces, healthcare, public services, community programs, organizational decision-making, or well-being initiatives would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, anti-coercion review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level PERMA index, profile-balance, and context-adjusted flourishing scoring example in C. |
| `cpp/` | C++ implementation for typed PERMA indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and institutional/context datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for PERMA profile scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for PERMA, institutional support, barriers, and flourishing dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, PERMA profile scoring, institutional context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures PERMA, flourishing, life-satisfaction, institutional-support, and barrier modeling. |
| `rust/` | Rust implementation for safe, explicit PERMA indicator scoring. |
| `sql/` | Relational schema and analytical views for PERMA research data. |
