# Flow and Optimal Experience in Positive Psychology

Professional computational scaffolding for the article `flow-and-optimal-experience-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for flow and optimal experience, including challenge level, skill level, challenge-skill balance, attentional focus, feedback quality, goal clarity, task meaning, autonomy support, distraction load, interruption count, flow score, performance, learning gain, fatigue, recovery, wellbeing, attentional ecology, sustainable flow, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, positive psychology researchers, educational psychologists, cognitive psychologists, creativity researchers, sport psychologists, work and organizational psychologists, human factors researchers, graduate students, methods instructors, and interdisciplinary attention/flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, productivity surveillance, benefits eligibility decisions, or individual psychological assessment. Applied use in schools, workplaces, healthcare, sport systems, design labs, digital products, public services, community programs, or organizational decision-making would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, anti-surveillance review, rest/recovery review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level flow, challenge-skill balance, attentional ecology, and sustainable-flow scoring example in C. |
| `cpp/` | C++ implementation for typed flow indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and attention-context datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for flow scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for challenge, skill, attention, distraction, fatigue, recovery, and performance dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, flow indices, attention-context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures flow, performance, learning, fatigue, recovery, and wellbeing modeling. |
| `rust/` | Rust implementation for safe, explicit flow indicator scoring. |
| `sql/` | Relational schema and analytical views for flow research data. |
