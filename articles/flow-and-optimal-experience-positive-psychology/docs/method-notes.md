# Method Notes

This companion scaffold treats flow as a dynamic state shaped by task conditions, attentional organization, motivation, feedback, and recovery.

A working challenge-skill balance model is:

```text
balance_index =
  high_level_engagement
- absolute(challenge - skill)
```

A working attentional-ecology model is:

```text
attentional_ecology =
  attention focus
+ feedback quality
+ goal clarity
- distraction load
- interruption count
```

A deep-engagement context model is:

```text
deep_engagement_context =
  balance index
+ attention focus
+ feedback quality
+ goal clarity
+ task meaning
+ autonomy support
- distraction load
- interruption count
```

A sustainable-flow model is:

```text
sustainable_flow =
  flow score
+ task meaning
+ autonomy support
+ recovery quality
- fatigue score
- distraction load
```

## Recommended research workflow

1. Inspect missingness, distributions, and scale direction.
2. Direction-correct distraction, interruption, and fatigue where needed.
3. Evaluate reliability separately by item family.
4. Preserve flow conditions, flow experience, and flow outcomes as distinct domains.
5. Model challenge-skill balance explicitly.
6. Measure feedback, goal clarity, autonomy, task meaning, distraction, interruptions, fatigue, and recovery alongside flow.
7. Model performance, learning, and well-being separately.
8. Use network models as exploratory flow-system maps, not causal proof.
9. Interpret results in relation to task design, institutions, digital tools, rest, disability access, skill development, workload, and surveillance risk.
10. Avoid treating flow scores as clinical measures, employment tools, productivity-surveillance tools, school-ranking tools, disciplinary tools, benefits tools, or individual assessments.

## Scope and use

These examples use synthetic data for research workflow demonstration, methods development, documentation, and reproducible analysis. They are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, student ranking, employee evaluation, productivity surveillance, benefits eligibility decisions, or individual psychological assessment.
