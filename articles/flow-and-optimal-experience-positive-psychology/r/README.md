# R Professional Flow and Optimal Experience Workflow

This workflow is designed for flow theory and positive psychology research methods:

- item-family reliability analysis;
- attention-context audit summary;
- challenge-skill balance scoring;
- attentional-ecology scoring;
- sustainable-flow scoring;
- repeated-measures flow modeling;
- performance modeling;
- learning-gain modeling;
- wellbeing modeling;
- sustainable-flow modeling;
- balance × attention interaction;
- meaning × autonomy interaction;
- flow × recovery interaction;
- estimated marginal means;
- domain summary tables;
- reproducible table exports.

## Suggested setup

```r
install.packages(c(
  "tidyverse",
  "psych",
  "lme4",
  "lmerTest",
  "broom.mixed",
  "emmeans",
  "performance"
))
```

Run:

```bash
Rscript flow_professional_models.R
```

## Scope

This is a synthetic-data scaffold for research workflow demonstration. It is not a validated psychological instrument and must not be used for clinical, employment, school disciplinary, productivity-surveillance, benefits eligibility, ranking, screening, or individual decision-making.
