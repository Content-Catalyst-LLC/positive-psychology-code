# Character Strengths and Virtues in Positive Psychology

Professional computational scaffolding for the article `character-strengths-virtues-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for character strengths and virtues, including VIA-style strength profiles, six virtue clusters, signature-strength use, authenticity, contextual support, institutional suppression, strength overuse, flourishing, wellbeing, meaning, relationships, engagement, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, positive psychology researchers, moral psychologists, educational psychologists, leadership researchers, organizational psychologists, counseling researchers, graduate students, methods instructors, and interdisciplinary flourishing/virtue research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, benefits eligibility decisions, moral ranking, or individual psychological assessment. Applied use in schools, workplaces, healthcare, counseling, public services, leadership programs, community programs, or organizational decision-making would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, religious/philosophical sensitivity review, disability/access review, power/context analysis, bias and fairness review, anti-coercion review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level virtue-cluster, signature-strength, and context-adjusted strength scoring example in C. |
| `cpp/` | C++ implementation for typed character-strength indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and institutional-context datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for virtue-cluster and strength-expression scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for strength expression, institutional support, suppression, overuse, and flourishing dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, virtue-cluster scoring, character-context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures character-strength, flourishing, meaning, relationship, and engagement modeling. |
| `rust/` | Rust implementation for safe, explicit character-strength indicator scoring. |
| `sql/` | Relational schema and analytical views for character-strength research data. |
