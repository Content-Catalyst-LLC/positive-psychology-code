# Subjective Well-Being and Life Satisfaction

Computational scaffolding for the article `subjective-wellbeing-life-satisfaction` in the Positive Psychology knowledge series.

This folder supports reproducible analysis of subjective well-being, life satisfaction, affect balance, social support, income security, meaning alignment, stress load, adaptation, and network structures of self-reported well-being.

Examples are synthetic and educational. They are not clinical, diagnostic, therapeutic, workplace-screening, employment-selection, or well-being assessment tools.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level subjective well-being composite example in C. |
| `cpp/` | C++ implementation for typed SWB indicator scoring. |
| `data/` | Synthetic sample datasets and processed outputs. |
| `docs/` | Data dictionary, method notes, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line analysis. |
| `julia/` | Julia workflow for matrix-based indicator modeling. |
| `notebooks/` | Notebook placeholders for exploratory analysis. |
| `outputs/` | Generated figures and tables. |
| `python/` | Python composite-index and network-analysis workflow. |
| `r/` | R longitudinal mixed-model workflow. |
| `rust/` | Rust implementation for safe, explicit SWB indicator scoring. |
| `sql/` | Relational schema and analytical view for SWB indicators. |

## Core variables

- life satisfaction
- positive affect
- negative affect
- social support
- income security
- meaning alignment
- stress load
- affect balance
