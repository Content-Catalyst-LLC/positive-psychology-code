# Validation Plan

Use this checklist before treating outputs as article-supporting evidence.

## Data validation

- Confirm source provenance for every indicator.
- Check variable direction so higher scores consistently mean better or worse conditions as intended.
- Inspect missingness by variable, region, year, and vulnerable subgroup.
- Compare imputed and complete-case outputs.

## Composite-index validation

- Test equal weights against theory-weighted alternatives.
- Vary penalty terms for carbon pressure and inequality.
- Report sensitivity of rankings and model coefficients.
- Avoid treating the composite score as an objective truth.

## Model validation

- Inspect residuals and leverage points.
- Test alternative functional forms.
- Evaluate temporal lag structures for ecological and institutional indicators.
- Run subgroup or regional checks where sample size permits.

## Communication validation

- Make uncertainty visible.
- Avoid implying causality from cross-sectional association.
- Disaggregate where averages conceal unequal exposure or burden.
