# Data Dictionary

| Variable | Type | Description |
|---|---:|---|
| `life_satisfaction` | numeric | Subjective evaluation of life as a whole. |
| `meaning` | numeric | Perceived purpose, coherence, and life meaning. |
| `health` | numeric | General physical and mental health indicator. |
| `social_trust` | numeric | Trust in neighbors, institutions, and civic life. |
| `institutional_quality` | numeric | Perceived or measured governance capacity, legitimacy, and reliability. |
| `ecological_integrity` | numeric | Ecological condition indicator such as biodiversity, air quality, water security, or ecosystem resilience. |
| `carbon_pressure` | numeric | Emissions, energy intensity, or carbon burden indicator. Higher values represent more pressure. |
| `inequality_index` | numeric | Inequality, precarity, or distributive-risk indicator. Higher values represent more inequality. |
| `income_security` | numeric | Material security and income stability. |
| `civic_participation` | numeric | Participation in civic, democratic, community, or collective action. |
| `sustainable_wellbeing_index` | numeric | Composite index combining positive well-being indicators with penalty terms for pressure and inequality. |
