# Post-Traumatic Growth in Positive Psychology

Professional computational scaffolding for the article `post-traumatic-growth-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for post-traumatic growth (PTG), including assumptive disruption, intrusive rumination, deliberate rumination, meaning-making, social support, restored agency, narrative integration, context support, ongoing stress burden, distress, wellbeing, PTG domain scores, perceived versus corroborated growth, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, trauma researchers, positive psychology researchers, counseling researchers, clinical researchers, resilience researchers, meaning-making researchers, graduate students, methods instructors, and interdisciplinary recovery/flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis triage, suicide/self-harm risk assessment, workplace screening, employment selection, student ranking, employee evaluation, public-benefits eligibility decisions, legal determinations, insurance decisions, or individual psychological assessment. Applied use in clinical, school, workplace, healthcare, public-service, legal, community, or organizational settings would require validated instruments, trauma expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, trauma-informed language review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level PTG integration, growth-distress balance, and recovery-context scoring example in C. |
| `cpp/` | C++ implementation for typed PTG indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and context-support datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for PTG process scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for disruption, rumination, meaning-making, support, agency, and integration dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, PTG indices, trauma-context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures PTG modeling, distress modeling, wellbeing modeling, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit PTG indicator scoring. |
| `sql/` | Relational schema and analytical views for PTG research data. |
