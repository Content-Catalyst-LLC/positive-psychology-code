# Validation Plan

This plan is intended for professional research use with real, ethically collected data.

## Data validation

- Confirm source provenance and collection context.
- Confirm item direction and reverse-code where appropriate.
- Check missingness by wave, group, item, and domain.
- Evaluate whether missingness is plausibly MCAR, MAR, or MNAR.
- Inspect outliers and impossible values.
- Document inclusion and exclusion rules.

## Psychometric validation

- Estimate reliability for each proposed scale.
- Inspect item-total correlations.
- Run exploratory factor analysis for dimensional structure.
- Run confirmatory factor analysis when theory and sample size justify it.
- Evaluate measurement invariance before comparing groups.
- Avoid using composite scores when the measurement model is unstable.

## Model validation

- Test alternative weighting rules for composite indicators.
- Compare complete-case, imputed, and sensitivity models.
- Inspect residuals and random-effects assumptions in longitudinal models.
- Bootstrap network centrality and edge stability.
- Avoid causal language unless the research design supports it.

## Ethical validation

- Assess privacy and identifiability risk.
- Avoid individual-level scoring for decisions unless validated for that purpose.
- Review potential bias and disparate impact.
- Use subgroup analysis to reveal inequity, not to stigmatize groups.
- Document limits clearly in outputs and article-adjacent interpretation.
