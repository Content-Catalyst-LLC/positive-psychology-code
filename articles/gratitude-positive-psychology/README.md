# Gratitude in Positive Psychology

Professional computational scaffolding for the article `gratitude-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for gratitude and well-being research, including gratitude orientation, appreciative attention, perceived support, resilience, stress load, depressive-symptom outcomes, life satisfaction, gratitude expression, reflection depth, intervention fit, relationship context, longitudinal mixed modeling, mechanism networks, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to positive psychology researchers, psychologists, gratitude researchers, relationship researchers, well-being scientists, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are professional research scaffolds, not validated clinical instruments or individual decision tools. Applied work with real people, schools, workplaces, healthcare settings, or community programs requires validated measures, appropriate ethics review, privacy safeguards, cultural adaptation, trauma-informed framing, domain expertise, and careful communication of uncertainty.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level appreciative-orientation and net-well-being scoring example in C. |
| `cpp/` | C++ implementation for typed gratitude mechanism scoring. |
| `data/` | Synthetic panel, network, item-family, relationship-context, and practice-quality datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for gratitude mechanism scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for gratitude, social support, stress-load, and well-being dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, appreciative-orientation indices, practice-quality audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for longitudinal gratitude modeling, interactions, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for gratitude research data. |
