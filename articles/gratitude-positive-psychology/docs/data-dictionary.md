# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `condition` | categorical | n/a | Gratitude-practice or comparison condition. |
| `gratitude_score` | numeric | higher is better | Gratitude orientation or gratitude-related state/disposition indicator. |
| `life_satisfaction` | numeric | higher is better | Cognitive evaluation of life quality. |
| `perceived_support` | numeric | higher is better | Perceived relational, social, or community support. |
| `resilience_score` | numeric | higher is better | Adaptive coping and resilience resource indicator. |
| `stress_load` | numeric | higher is worse | Contextual strain and burden. |
| `depressive_symptoms` | numeric | higher is worse | Synthetic distress/symptom-burden indicator for demonstration only. |
| `reflection_depth` | numeric | higher is better | Degree of meaningful explanation or interpretive reflection. |
| `gratitude_expression` | numeric | higher is better | Expressed acknowledgment, thanks, or appreciation. |
| `intervention_fit` | numeric | higher is better | Fit between the gratitude practice and the participant context. |
| `relationship_quality` | numeric | higher is better | Quality of close or salient relationships. |
| `social_trust` | numeric | higher is better | Trust in relational or community support. |

## Practice-quality variables

| Variable | Description |
|---|---|
| `reflection_design` | Whether the practice supports meaningful reflection rather than mechanical listing. |
| `mechanism_clarity` | Clarity about the psychological mechanism being targeted. |
| `acceptability` | Perceived usefulness and low burden. |
| `context_fit` | Cultural, relational, developmental, and situational fit. |
| `privacy_safeguards` | Data protection for reflective and well-being data. |
| `trauma_sensitive_language` | Degree to which language avoids forced gratitude or minimization of distress. |
| `relational_safety` | Whether direct gratitude expression is safe and appropriate. |
| `measurement_quality` | Strength of measurement design, documentation, and interpretation limits. |
| `overall_practice_quality` | Transparent average-like summary used for teaching; not a validated score. |

## Indicator-bank variables

- `gratitude1` to `gratitude2`: gratitude indicators.
- `attention1` to `attention2`: appreciative-attention indicators.
- `support1` to `support2`: perceived-support indicators.
- `resilience1` to `resilience2`: resilience indicators.
- `reflection1` to `reflection2`: reflection-depth indicators.
- `expression1` to `expression2`: gratitude-expression indicators.
- `fit1` to `fit2`: intervention-fit indicators.
- `wellbeing1` to `wellbeing2`: positive well-being indicators.
- `distress1` to `distress2`: distress indicators, where higher is worse.
- `relationship1` to `relationship2`: relationship-quality indicators.
