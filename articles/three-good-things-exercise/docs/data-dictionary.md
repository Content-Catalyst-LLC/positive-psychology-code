# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `life_satisfaction` | numeric | higher is better | Cognitive evaluation of life quality. |
| `depressive_symptoms` | numeric | higher is worse | Synthetic distress/symptom-burden indicator for demonstration only. |
| `gratitude_score` | numeric | higher is better | Gratitude or appreciative-affect indicator. |
| `positive_event_salience` | numeric | higher is better | Ease and frequency of noticing positive events. |
| `perceived_support` | numeric | higher is better | Perceived relational or social support. |
| `reflection_depth` | numeric | higher is better | Degree of meaningful explanation in the “why did this happen?” step. |
| `stress_load` | numeric | higher is worse | Cumulative strain or stress burden. |
| `acceptability` | numeric | higher is better | Participant-perceived acceptability of the practice. |
| `context_fit` | numeric | higher is better | Fit between the practice and the participant’s life context, culture, or needs. |

## Practice-quality variables

| Variable | Description |
|---|---|
| `completion_rate` | Synthetic degree to which the practice was completed as intended. |
| `reflection_depth` | Synthetic quality of causal reflection. |
| `acceptability` | Synthetic perceived usefulness and non-burdensomeness. |
| `context_fit` | Synthetic cultural, developmental, and situational fit. |
| `privacy_safeguards` | Synthetic strength of privacy and journaling-data protection. |
| `trauma_sensitive_language` | Synthetic degree to which prompts avoid forced positivity. |
| `implementation_support` | Synthetic support for practicing safely and meaningfully. |
| `overall_practice_quality` | Transparent average-like summary used for teaching; not a validated score. |

## Indicator-bank variables

- `salience1` to `salience2`: positive event salience indicators.
- `gratitude1` to `gratitude2`: gratitude indicators.
- `support1` to `support2`: perceived support indicators.
- `reflection1` to `reflection2`: reflection depth indicators.
- `wellbeing1` to `wellbeing2`: positive well-being indicators.
- `distress1` to `distress2`: distress indicators, where higher is worse.
- `fit1` to `fit2`: fit and acceptability indicators.
