# Method Notes

This companion scaffold treats Three Good Things as an intervention on attention, causal reflection, gratitude, memory, and narrative interpretation.

A working conceptual model is:

```text
appreciative awareness =
  positive event salience
+ gratitude
+ perceived support
+ reflection depth
+ context fit
- stress load
```

A basic net well-being index can be represented as:

```text
net well-being =
  life satisfaction
+ gratitude
+ positive event salience
+ perceived support
+ reflection depth
- depressive symptoms
- stress load
```

Practice quality can be represented as:

```text
practice quality =
  completion rate
+ reflection depth
+ acceptability
+ context fit
+ privacy safeguards
+ trauma-sensitive language
+ implementation support
```

## Recommended research workflow

1. Inspect missingness, distributions, and scale direction.
2. Direction-correct depressive symptoms, distress indicators, and stress load.
3. Evaluate reliability separately by item family.
4. Preserve mechanism scores before building composite indices.
5. Document weights and test sensitivity to alternative weights.
6. Fit repeated-measures models when daily or longitudinal observations are available.
7. Use network models as exploratory mechanism maps, not causal proof.
8. Evaluate acceptability and fit before recommending repeated use.
9. Interpret results alongside context, stress load, and participant feedback.
10. Avoid treating reflective-practice scores as clinical measures, employment tools, or individual assessments.

## Scope and use

These examples use synthetic data for research workflow demonstration, methods development, documentation, and reproducible analysis. They are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis support, workplace screening, employment selection, public-benefits eligibility decisions, or individual well-being assessment.
