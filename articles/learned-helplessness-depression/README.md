# Learned Helplessness and Depression in Positive Psychology

Professional computational scaffolding for the article `learned-helplessness-depression` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for learned helplessness, perceived control, uncontrollability, attribution, motivation, recovery, agency, support, institutional fairness, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, positive psychology researchers, attribution researchers, resilience researchers, educational psychologists, counseling researchers, health psychologists, organizational psychologists, public-health researchers, graduate students, methods instructors, and interdisciplinary agency/flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis support, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, benefits eligibility decisions, or individual psychological assessment. Applied use in schools, workplaces, healthcare, counseling, public services, community programs, organizational decision-making, or resilience-training systems would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, anti-coercion review, clinical escalation protocols where relevant, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level helplessness-index, control-gap, and agency-recovery scoring example in C. |
| `cpp/` | C++ implementation for typed learned-helplessness indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and institutional/context datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for learned-helplessness scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for controllability, uncontrollability, attribution, motivation, support, recovery, and agency dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, helplessness indices, context audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures helplessness, motivation, depressive-symptom, and agency-recovery modeling. |
| `rust/` | Rust implementation for safe, explicit learned-helplessness indicator scoring. |
| `sql/` | Relational schema and analytical views for learned-helplessness research data. |
