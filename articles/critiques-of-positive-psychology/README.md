# Critiques of Positive Psychology

Professional computational scaffolding for the article `critiques-of-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for critiques of positive psychology, including psychological predictors of flourishing, structural conditions, institutional trust, inequality exposure, stress load, cultural fit, environmental quality, construct distortion, commercialization risk, measurement validity, and network structures of critique-sensitive flourishing research.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, well-being researchers, critical psychology scholars, public-policy analysts, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, public-benefits eligibility decisions, or individual well-being assessment. Applied use in health, education, employment, public services, organizational decision-making, public policy, or community intervention would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, community interpretation, bias and fairness review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level critique-sensitive flourishing composite example in C. |
| `cpp/` | C++ implementation for typed critique-sensitive scoring. |
| `data/` | Synthetic panel, network, construct-distortion, and indicator-family datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for construct distortion and institutional uptake. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, and diagnostics. |
| `python/` | Python workflow for composite indicators, PCA, Graphical Lasso networks, and bootstrap stability. |
| `r/` | R workflow for model comparison, mixed models, reliability checks, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for critique-sensitive flourishing data. |
