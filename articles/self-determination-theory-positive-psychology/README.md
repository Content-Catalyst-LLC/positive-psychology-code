# Self-Determination Theory in Positive Psychology

Professional computational scaffolding for the article `self-determination-theory-positive-psychology` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for Self-Determination Theory, including autonomy support, competence support, relatedness support, need satisfaction, need frustration, controlling pressure, autonomous motivation, controlled motivation, internalization, motivational quality, vitality, stress load, well-being, domain context, network analysis, validation, and responsible interpretation.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, motivational scientists, educational psychologists, organizational researchers, health-behavior researchers, sport psychologists, developmental researchers, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, crisis support, workplace screening, employment selection, school disciplinary decisions, student ranking, employee evaluation, public-benefits eligibility decisions, or individual psychological assessment. Applied use in schools, workplaces, healthcare, sport, public services, community programs, or organizational decision-making would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, disability/access review, power/context analysis, bias and fairness review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level SDT need-balance and motivational-quality scoring example in C. |
| `cpp/` | C++ implementation for typed SDT indicator scoring. |
| `data/` | Synthetic panel, network, item-family, and motivational-climate datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for SDT scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for need support, internalization, stress, and well-being dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, SDT indices, motivational-climate audit, Graphical Lasso networks, PCA, and bootstrap stability. |
| `r/` | R workflow for repeated-measures SDT modeling, interactions, mediation-style summaries, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit SDT indicator scoring. |
| `sql/` | Relational schema and analytical views for SDT data. |
