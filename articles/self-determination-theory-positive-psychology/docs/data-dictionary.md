# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `domain` | categorical | n/a | Applied context such as education, work, health, or sport. |
| `autonomy_support` | numeric | higher is better | Voice, choice, meaningful rationale, volition, and non-controlling guidance. |
| `competence_support` | numeric | higher is better | Feedback, optimal challenge, skill development, scaffolding, and mastery support. |
| `relatedness_support` | numeric | higher is better | Belonging, trust, care, recognition, and relational safety. |
| `need_frustration` | numeric | higher is worse | Active frustration of autonomy, competence, or relatedness. |
| `controlling_pressure` | numeric | higher is worse | Coercion, surveillance, shame, pressure, or externally controlling climate. |
| `autonomous_motivation` | numeric | higher is better | Self-endorsed motivation, including identified, integrated, and intrinsic motivation. |
| `controlled_motivation` | numeric | higher is worse | Externally pressured or internally pressured motivation. |
| `internalization` | numeric | higher is better | Degree to which values or goals are understood, endorsed, and integrated. |
| `wellbeing_score` | numeric | higher is better | Synthetic well-being or flourishing outcome score. |
| `vitality` | numeric | higher is better | Subjective vitality and energetic functioning. |
| `stress_load` | numeric | higher is worse | Contextual strain and stress burden. |
| `climate_quality` | numeric | higher is better | Overall motivational climate quality. |

## Motivational-climate audit variables

| Variable | Description |
|---|---|
| `autonomy_support_design` | Degree to which the setting supports voice, rationale, and self-endorsement. |
| `competence_scaffolding` | Degree to which the setting provides feedback, challenge fit, and pathways to mastery. |
| `relatedness_climate` | Degree to which the setting supports trust, belonging, and relational care. |
| `need_frustration_risk` | Risk of coercion, shame, chaos, humiliation, rejection, or alienation. |
| `privacy_safeguards` | Data protection and confidentiality standards for motivation/well-being data. |
| `power_context_review` | Attention to hierarchy, coercion, vulnerability, consent, and institutional power. |
| `measurement_quality` | Strength of measurement design, documentation, and interpretation limits. |
| `overall_climate_quality` | Transparent average-like summary used for teaching; not a validated score. |

## Indicator-bank variables

- `autonomy1` to `autonomy2`: autonomy support indicators.
- `competence1` to `competence2`: competence support indicators.
- `relatedness1` to `relatedness2`: relatedness support indicators.
- `frustration1` to `frustration2`: need-frustration indicators, where higher is worse.
- `autonomous1` to `autonomous2`: autonomous motivation indicators.
- `controlled1` to `controlled2`: controlled motivation indicators, where higher is worse.
- `internalization1` to `internalization2`: internalization indicators.
- `wellbeing1` to `wellbeing2`: well-being indicators.
- `vitality1` to `vitality2`: vitality indicators.
