# Method Notes

This companion scaffold treats Self-Determination Theory as a motivational-climate framework.

A working need-support model is:

```text
need support =
  autonomy support
+ competence support
+ relatedness support
```

A need-balance model is:

```text
need balance =
  average need support
- controlling pressure
- need frustration
```

A motivational-quality model is:

```text
motivational quality =
  autonomous motivation
+ internalization
- controlled motivation
```

A net well-being model is:

```text
net SDT wellbeing =
  wellbeing score
+ vitality
+ autonomous motivation
+ internalization
+ need support
- controlled motivation
- stress load
- need frustration
- controlling pressure
```

## Recommended research workflow

1. Inspect missingness, distributions, and scale direction.
2. Direction-correct need frustration, controlled motivation, controlling pressure, and stress load.
3. Evaluate reliability separately by item family.
4. Preserve need-specific scores before building composites.
5. Distinguish need support from need frustration.
6. Model motivational quality separately from observed behavior.
7. Fit repeated-measures models when longitudinal observations are available.
8. Use network models as exploratory motivational-climate maps, not causal proof.
9. Interpret results in relation to context, power, culture, hierarchy, disability access, and institutional conditions.
10. Avoid treating SDT scores as clinical measures, employment tools, disciplinary tools, or individual assessments.

## Scope and use

These examples use synthetic data for research workflow demonstration, methods development, documentation, and reproducible analysis. They are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, student ranking, employee evaluation, school disciplinary decisions, public-benefits eligibility decisions, or individual psychological assessment.
