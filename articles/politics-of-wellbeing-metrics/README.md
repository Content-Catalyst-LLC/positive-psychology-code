# The Politics of Well-Being Metrics

Computational scaffolding for the article `politics-of-wellbeing-metrics` in the Positive Psychology knowledge series.

This folder supports reproducible analysis of well-being metrics, public policy measurement, composite indicator design, dashboard governance, institutional trust, inequality, environmental quality, democratic quality, and the politics of public well-being measurement.

Examples are synthetic and educational. They are not clinical, diagnostic, therapeutic, workplace-screening, or well-being assessment tools.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level composite-index example in C. |
| `cpp/` | C++ implementation for typed indicator scoring. |
| `data/` | Synthetic sample datasets and processed outputs. |
| `docs/` | Data dictionary, method notes, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line analysis. |
| `julia/` | Julia workflow for matrix-based indicator modeling. |
| `notebooks/` | Notebook placeholders for exploratory analysis. |
| `outputs/` | Generated figures and tables. |
| `python/` | Python composite-index, PCA, and network-analysis workflow. |
| `r/` | R longitudinal mixed-model workflow. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical view for well-being indicators. |
