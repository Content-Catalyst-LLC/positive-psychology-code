# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `life_satisfaction` | numeric | higher is better | Subjective life evaluation. |
| `health_index` | numeric | higher is better | General health, functioning, or public-health condition. |
| `trust_index` | numeric | higher is better | Social and institutional trust. |
| `income_security` | numeric | higher is better | Household economic security and income stability. |
| `housing_quality` | numeric | higher is better | Housing quality, safety, and stability. |
| `education_access` | numeric | higher is better | Access to education and learning opportunity. |
| `democratic_quality` | numeric | higher is better | Democratic legitimacy, voice, accountability, and institutional openness. |
| `environmental_quality` | numeric | higher is better | Environmental condition, exposure, and future-oriented quality. |
| `inequality_index` | numeric | higher is worse | Inequality, precarity, or distributional burden. |
| `policy_exposure` | numeric | context dependent | Exposure to a public policy, program, budget priority, or intervention. |
