# Data Dictionary

| Variable | Type | Direction | Description |
|---|---:|---|---|
| `autonomy_support` | numeric | higher is better | Degree of meaningful choice, voice, judgment, and self-endorsed action. |
| `competence_growth` | numeric | higher is better | Developmental opportunity, skill growth, learning, and mastery. |
| `relatedness_trust` | numeric | higher is better | Connection, respect, belonging, and interpersonal/institutional trust. |
| `work_meaning` | numeric | higher is better | Perceived purpose, usefulness, and meaningful contribution. |
| `psychological_safety` | numeric | higher is better | Ability to speak, ask questions, admit mistakes, and dissent without fear. |
| `supervisor_support` | numeric | higher is better | Managerial support, clarity, coaching, and responsive problem-solving. |
| `recovery_capacity` | numeric | higher is better | Ability to rest, detach, recover, and maintain sustainable effort. |
| `role_overload` | numeric | higher is worse | Excessive work demands, time pressure, and workload strain. |
| `job_insecurity` | numeric | higher is worse | Perceived employment instability, precarity, and threat of job loss. |
| `burnout_risk` | numeric | higher is worse | Exhaustion, cynicism, reduced efficacy, or depletion risk. |
