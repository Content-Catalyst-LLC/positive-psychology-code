# Well-Being, Work, and Institutional Design

Computational scaffolding for the article `wellbeing-work-institutional-design` in the Positive Psychology knowledge series.

This folder supports reproducible analysis of workplace well-being, institutional design, self-determination theory, autonomy support, competence growth, relatedness and trust, psychological safety, overload, insecurity, recovery capacity, burnout risk, and network structures of workplace flourishing.

Examples are synthetic and educational. They are not clinical, diagnostic, therapeutic, workplace-screening, employment-selection, or well-being assessment tools.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level composite workplace-flourishing example in C. |
| `cpp/` | C++ implementation for typed workplace indicator scoring. |
| `data/` | Synthetic sample datasets and processed outputs. |
| `docs/` | Data dictionary, method notes, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line analysis. |
| `julia/` | Julia workflow for matrix-based indicator modeling. |
| `notebooks/` | Notebook placeholders for exploratory analysis. |
| `outputs/` | Generated figures and tables. |
| `python/` | Python network-analysis workflow for workplace flourishing. |
| `r/` | R longitudinal mixed-model workflow. |
| `rust/` | Rust implementation for safe, explicit workplace indicator scoring. |
| `sql/` | Relational schema and analytical view for workplace well-being indicators. |
