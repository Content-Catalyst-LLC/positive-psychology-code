# The Science of Flourishing: How Positive Psychology Measures Well-Being

Professional computational scaffolding for the article `science-of-flourishing-measuring-well-being` in the Positive Psychology knowledge series.

This companion folder supports reproducible research workflows for the scientific measurement of flourishing, including hedonic well-being, eudaimonic functioning, relational support, meaning and purpose, accomplishment and agency, health capacity, contextual support, cumulative strain, measurement quality, reliability, validity, cultural comparability, temporal sensitivity, use validity, longitudinal modeling, and network structures of well-being.

## Scope

This repository provides synthetic-data examples for research workflow demonstration, methods development, documentation, and reproducible analysis. It is designed to be useful to psychologists, well-being researchers, psychometricians, public-policy analysts, public-health researchers, graduate students, methods instructors, and interdisciplinary flourishing research teams.

These materials are not designed for clinical diagnosis, treatment planning, therapeutic intervention, workplace screening, employment selection, public-benefits eligibility decisions, or individual well-being assessment. Applied use in health, education, employment, public services, organizational decision-making, public policy, or community intervention would require validated instruments, domain expertise, ethical review where appropriate, informed consent where appropriate, privacy safeguards, cultural adaptation, community interpretation, bias and fairness review, and compliance with applicable legal and ethical standards.

## Repository structure

| Folder | Purpose |
|---|---|
| `c/` | Low-level multidimensional flourishing composite example in C. |
| `cpp/` | C++ implementation for typed flourishing measurement scoring. |
| `data/` | Synthetic panel, network, item-family, and measurement-quality datasets. |
| `docs/` | Data dictionary, method notes, validation plan, ethics scope, table CSS note, and WordPress GitHub embed block. |
| `fortran/` | Fortran numerical example for composite scoring. |
| `go/` | Go implementation for reproducible command-line scoring. |
| `julia/` | Julia simulation for measurement-quality and flourishing dynamics. |
| `notebooks/` | Notebook placeholders for exploratory and teaching workflows. |
| `outputs/` | Generated figures, tables, model summaries, diagnostics, and reports. |
| `python/` | Python workflow for reliability, composite indicators, PCA, Graphical Lasso networks, and bootstrap stability. |
| `r/` | R workflow for reliability checks, mixed models, interactions, and estimated margins. |
| `rust/` | Rust implementation for safe, explicit indicator scoring. |
| `sql/` | Relational schema and analytical views for multidimensional flourishing data. |
